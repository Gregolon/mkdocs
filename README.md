# Documentação do PSP Legacy | Archive

Site de documentação feito com MkDocs (tema Material), publicado no GitHub Pages.

## Ambiente virtual

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Visualizar localmente

```bash
mkdocs serve
```

## Publicação

```bash
mkdocs gh-deploy
```
